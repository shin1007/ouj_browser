# ouj-chromium-extension

このプロジェクトは、放送大学の放送授業を利用しやすくするためのChromium拡張機能です。以下の機能を提供します。

## 機能

- 自動ログイン機能
- 放送授業へのリンク一覧表示
- 音声のみ再生（映像を消す）
- オープニングとエンディングの削除
- 再生位置の保存
- ローカルでの倍速・低速再生機能およびその保存
- お気に入り機能
- タイトルの自動読み上げ
- 自動で次の動画を再生（同じ科目、お気に入りからランダム、お気に入りから順番に）
- 自動で次（放送回ランダム）
- 自動で次（未視聴のみ）

## インストール手順

1. このリポジトリをクローンまたはダウンロードします。
2. `src/manifest.json`を開き、必要に応じて設定を変更します。
3. Chromiumブラウザを開き、拡張機能の管理ページに移動します。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`ouj-chromium-extension/src`フォルダを選択します。
5. 拡張機能がインストールされます。

## 使用方法

拡張機能をインストールした後、ブラウザのツールバーに表示されるアイコンをクリックしてポップアップを開きます。ここから各機能にアクセスできます。

## 開発

このプロジェクトは、JavaScriptを使用して開発されています。各ファイルの役割は以下の通りです。

- `src/background.js`: 拡張機能のバックグラウンドスクリプト
- `src/content.js`: ウェブページに挿入されるコンテンツスクリプト
- `src/popup/popup.html`: ポップアップUIのHTML
- `src/popup/popup.js`: ポップアップのJavaScript
- `src/options/options.html`: オプション設定用のHTML
- `src/options/options.js`: オプション設定のJavaScript
- `src/utils/helpers.js`: ユーティリティ関数を含むヘルパースクリプト
- `src/manifest.json`: 拡張機能の設定ファイル
- `package.json`: npmの設定ファイル
